## ทำต่ออย่างไร

1. เปิดหน้า **Dataset Review** กรองหมวด แล้วตรวจ Transcript กับคลิปจริงว่าไม่ใช่สรุป ไม่มีข้อความแต่ง และเสนอหมวดถูก
2. Approve เฉพาะรายการที่ผ่าน พร้อมบันทึกหมายเหตุ ส่วนที่ไม่ผ่านให้แก้หรือ Reject
3. กลับหน้า **Train AI > แผนเก็บข้อมูลเพิ่ม** เพื่อดูจำนวนที่ใช้ได้จริงหลังอนุมัติ
4. ก่อนเก็บ Unknown ให้ตรวจรหัสช่องว่าอยู่ Validation หรือ Test อย่าเก็บจากช่อง Train แล้วค่อยย้ายชุด
5. เมื่อข้อมูลพร้อมจึงฝึกและประเมิน ไม่เปลี่ยนโมเดลจริงเพียงเพราะครบจำนวน

## โค้ดและหลักฐาน

- `frontend_flutter/lib/utils/notebooklm_markdown_parser.dart`: ตัวอ่านเดียวกับหน้าเว็บ ตัดหัวข้อ Segment ที่ไม่ใช่คำพูด และปฏิเสธข้อความแจ้งว่าไม่มี Transcript
- `frontend_flutter/tool/export_notebooklm_batch.dart`: อ่าน Markdown เป็น JSON โดยไม่แก้ต้นฉบับ
- `scripts/import_notebooklm_batch.py`: ตรวจซ้ำ/Video ID/การแบ่งช่อง, ขอ Metadata เป็นชุด, นำเข้าเป็นรอตรวจเท่านั้น
- `artifacts/imports/notebooklm-20260928/import-result.json`: รายงานรายไฟล์ รหัสชุดนำเข้า ข้อมูลช่อง Split และ Fingerprint ก่อน/หลัง
- `tests/test_notebooklm_batch.py`: ทดสอบการนำเข้าซ้ำ การไม่อนุมัติอัตโนมัติ และการไม่แจ้งสำเร็จเมื่อบันทึกถูกปฏิเสธ

สคริปต์ค่าเริ่มต้นเป็นอ่านอย่างเดียว; `--fetch-metadata` ขอข้อมูลจาก YouTube แต่ไม่เขียน Database
ต้องระบุ `--apply --admin-user-id <รหัส Admin ที่ใช้งาน>` จึงจะเพิ่มคิวรอตรวจ และไม่มีตัวเลือกอนุมัติหรือ Train
รายงานทุกครั้งใช้ชื่อไฟล์ใหม่ ไม่มีการเขียนทับรายงานเดิม
