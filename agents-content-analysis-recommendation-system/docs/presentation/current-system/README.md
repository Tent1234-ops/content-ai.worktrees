## ภาพรวมที่ต้องเข้าใจก่อน

**เป้าหมายของระบบ:** ช่วยผู้สร้างคอนเทนต์เลือกเรื่องจากข้อมูลเทรนด์ และตรวจเนื้อหาที่พูดในคลิปเพื่อวางแผนปรับปรุง โดยแสดงที่มาของข้อมูล ไม่รับประกันยอดวิว

ระบบมีสามทางเดินข้อมูล อย่ารวมว่าเป็น AI ก้อนเดียว:

```text
ทางที่ 1: YouTube / Google -> เก็บเทรนด์ตามเวลา -> ฐานข้อมูล -> Dashboard/กราฟ
ทางที่ 2: Transcript ที่ Admin ตรวจ -> แบ่งตามช่อง -> ฝึกโมเดลจำแนกหมวด -> ไฟล์โมเดล
ทางที่ 3: คลิปผู้ใช้ -> Whisper -> ข้อความ -> โมเดลจำแนกหมวด -> ตรวจรับหมวด
         -> คลิปอ้างอิงที่เหมาะสม -> หาประเด็นที่ยังไม่พบ -> คำแนะนำและหลักฐาน
```

| ชั้นของระบบ | เทคโนโลยี/หน้าที่ | สิ่งที่ไม่ใช่ |
|---|---|---|
| Frontend | Flutter Web แสดงหน้าเว็บ ส่งคำขอ และแสดงสถานะงาน | ไม่ได้ฝึก AI ใน Browser |
| Backend | FastAPI/Python ตรวจสิทธิ์ อ่านข้อมูล ประมวลผล และบันทึก | ไม่ได้เชื่อทุกค่าที่ Frontend ส่งมาโดยไม่ตรวจ |
| Database | MySQL, เข้าถึงผ่าน SQLAlchemy | ไม่ใช่ที่เก็บน้ำหนัก Whisper ทั้งก้อน |
| ถอดเสียง | faster-whisper ใช้โมเดลที่ติดตั้งในเครื่อง | ไม่ใช่โมเดล Phone/Camera/Laptop ที่เราฝึก |
| จำแนกหมวด | scikit-learn และตัวเลือก multilingual embedding + classifier | ไม่ได้ใช้ยอดวิวตัดสินว่าผู้ใช้อัปคลิปหมวดใด |
| คำแนะนำ | กฎและแม่แบบภาษาไทยที่เชื่อมหลักฐาน Transcript/สถิติ | ไม่ใช่ ChatGPT ที่แต่งคำแนะนำโดยไม่มีแถวข้อมูลอ้างอิง |
| งานเบื้องหลัง | คิววิเคราะห์, worker เทรน, ตัวเก็บเทรนด์/Task Scheduler | ไม่ได้รันการเทรนค้างอยู่ใน HTTP request เดียว |

## คำศัพท์ฉบับสั้น

| คำ | แปลแบบใช้ในโปรเจคนี้ |
|---|---|
| Transcript | ข้อความจากเสียงพูดในคลิป |
| Metadata | ข้อมูลประกอบ เช่น ชื่อคลิป ช่อง วันที่เผยแพร่ ยอดวิว ความยาว |
| Snapshot | ภาพของข้อมูลที่ระบบเก็บได้ ณ เวลาหนึ่ง ไม่ใช่ข้อมูลทุกวินาที |
| Dataset | ชุดข้อมูลที่เตรียมไว้ บางแถวใช้ฝึก บางแถวใช้ตรวจ บางแถวใช้เป็นหลักฐาน |
| Feature | ตัวเลขที่แทนลักษณะข้อความเพื่อให้โมเดลคำนวณได้ ไม่จำเป็นต้องเป็น Keyword ที่แสดงบนจอ |
| Model | ตัวแปลงข้อมูลและค่าที่เรียนรู้ไว้ เพื่อทายหมวดจากข้อความใหม่ |
| Artifact | ไฟล์ที่ได้จากการฝึก เช่น `model.joblib`, manifest และรายงาน ไม่ใช่โค้ด `.py` ที่ AI เขียนขึ้นใหม่ |
| Evaluate | ให้โมเดลทายข้อมูลที่รู้คำตอบจริง แล้วคำนวณว่าถูกผิดอย่างไร |
| Confidence | คะแนนเชื่อมั่นต่อคำตอบของโมเดล ไม่ใช่โอกาสที่คลิปจะดัง |
| Unknown | ระบบยังไม่ยอมรับว่าอยู่ในหนึ่งในสามหมวด อาจนอกขอบเขต หรือหลักฐาน/โมเดลไม่พร้อม |
| Evidence | ข้อความ สถิติ เวลา URL และรหัสแถวที่รองรับข้อเสนอหนึ่งข้อ |
| Data leakage | ข้อมูลคำตอบ/ข้อมูลใกล้กันมากหลุดจากชุดฝึกไปชุดประเมินจนคะแนนดูดีเกินจริง |

เปิดเว็บ: `http://127.0.0.1:8080/#/dashboard` ส่วน API: `http://127.0.0.1:8000/docs`
