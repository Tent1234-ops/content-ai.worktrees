# ลำดับสาธิตและคำถาม

## ลำดับสาธิตที่ใช้ข้อมูลจริง

1. เปิด `/health` และอธิบาย Database, ASR และแหล่งเทรนด์ตามสถานะจริง ถ้าเป็น `degraded` ให้ชี้ว่าเกิดจาก Legacy TikTok provider และรุ่นส่งมอบรองรับ YouTube/Google เท่านั้น
2. เปิดหน้า Dashboard เพื่อสาธิตเทรนด์ โดยไม่โยงกราฟเทรนด์เข้ากับ Outcome Probability
3. เข้าสู่ระบบและเปิดผลที่บันทึกจริงประเภท Recommendation จากรายการที่ Release manifest ระบุเป็น `historical_saved_result` อธิบาย "พบอะไร -> ควรเพิ่มอะไร -> วิธีเพิ่ม -> หลักฐาน"
4. เปิดผลที่บันทึกจริงประเภท Unknown/Withheld เพื่อสาธิตว่าระบบงดคำแนะนำเฉพาะหมวดเมื่อไม่มั่นใจ
5. เปิดหน้า Admin Outcome Training แสดงจำนวนข้อมูล Gate และเหตุผลที่ปุ่มฝึก/Activate ถูกปิด
6. อธิบายว่า Outcome model ปัจจุบัน Registered 0 และ Active 0 จึงไม่มี Probability หรือ Scenario จริงให้สาธิต
7. เปิดเอกสาร Algorithm อธิบาย Fit median, Logistic Regression, Calibration, Baseline และ Test โดยไม่ใช้ Fixture เป็นผลจริง
8. เปิด Release manifest เพื่อยืนยัน Source hash, Schema hash, Backup/Restore และข้อจำกัด

อย่าเปิด Transcript หรือฐานข้อมูลจาก Private backup ระหว่างพรีเซนต์ และอย่าใส่รหัสผ่านในสไลด์หรือเอกสาร

## ถ้า Live demo ใช้ไม่ได้

ใช้ผลที่บันทึกจริงตาม Release manifest และพูดว่า "นี่คือผลที่ระบบบันทึกไว้ก่อนหน้า" ทุกครั้ง ห้ามพูดว่าเพิ่งวิเคราะห์สดหรือเป็นข้อมูลล่าสุด Browser screenshot จาก Fixture ใช้ยืนยัน Layout/State เท่านั้น ไม่ใช้ยืนยันว่าโมเดลผ่านหรือข้อมูลเป็นของจริง

หาก Backend ใช้ไม่ได้ ให้เปิดเอกสารและ Artifact ใน `shareable-package` อธิบายสถานะ `NO_GO` ตามเดิม ห้ามเปลี่ยนไปใช้ตัวเลขตัวอย่างโดยไม่ติดป้าย

## คำถามสำคัญ

### รู้ได้อย่างไรว่าทำตามคำแนะนำแล้วยอดวิวจะเพิ่ม

ตอนนี้ยังรู้ไม่ได้ในเชิงเหตุและผล ระบบที่ออกแบบประเมินเพียงความสัมพันธ์ว่า ภายในกลุ่มอ้างอิงที่ใกล้กัน คลิปที่มีลักษณะนี้มีโอกาสอยู่เหนือค่ากลางเท่าใด ปัจจัยอื่นไม่ได้ถูกควบคุมครบ จึงพูดได้เพียงว่า "เป็นประเด็นที่น่าลองโดยมีหลักฐานจากกลุ่มอ้างอิง" ไม่ใช่ "เพิ่มแล้ววิวจะขึ้น" การพิสูจน์ผลจริงต้องติดตามคลิปก่อน/หลังหรือทำการทดลองที่ควบคุมปัจจัยเพิ่ม

### เปอร์เซ็นต์หมายถึงอะไร

หมายถึงค่าประเมินของโมเดลว่าจะอยู่ในกลุ่มยอดวิวสูงกว่าค่ากลางของ Fit ภายใต้หมวด รูปแบบ และช่วงอายุที่ระบุ เมื่อโมเดลผ่านการรับรองแล้วเท่านั้น ไม่ใช่เปอร์เซ็นต์ยอดวิวเพิ่มและไม่ใช่โอกาสไวรัล

### ทำไมไม่ใช้ยอดวิวโดยตรง

ยอดวิวสะสมเปรียบเทียบตรง ๆ ไม่ยุติธรรมต่อคลิปต่างอายุและต่างขนาดช่อง จึงต้องกำหนดกลุ่มอ้างอิง แยกช่วงอายุ และถ่วงน้ำหนักแต่ละช่องเท่ากัน แม้อย่างนั้นยังเป็น Association ไม่ใช่ Causation

### Median มาจากไหน

มาจาก Fit partition เท่านั้น คำนวณภายใน Cell ที่ตรงกันและให้น้ำหนักรวมของแต่ละช่องเท่ากัน จากนั้น Freeze ค่านี้ก่อนใช้กับ Validation, Calibration และ Test

### ทำไมต้องมี Baseline

เพื่อพิสูจน์ว่า Topic ช่วยมากกว่าการเดาค่ากลางหรือใช้ Metadata ทั่วไป ถ้า Candidate ไม่ดีกว่า Baseline ตาม Margin ที่กำหนด ก็ไม่มีเหตุผลเปิดใช้โมเดลที่ซับซ้อนกว่า

### Validation กับ Test ต่างกันอย่างไร

Validation ใช้เลือก Candidate และค่าตั้ง ส่วน Independent Test เก็บไว้ตรวจรุ่นที่ Freeze แล้วครั้งสุดท้าย ห้ามนำผล Test กลับไปแก้โมเดล เพราะจะทำให้คะแนนไม่เป็นอิสระ

### ทำไมใช้ Brier score

Brier score วัดระยะห่างระหว่าง Probability กับผล 0/1 จึงตรวจทั้งความถูกต้องและความมั่นใจเกินจริง ค่ายิ่งต่ำยิ่งดี และต้องเทียบกับ Baseline ไม่อ่านค่าเดี่ยว ๆ

### ทำไมไม่ใช้ยอดวิวสะสมเป็น Growth หรือ 7-day views

ยอดสะสมไม่มีจุดเริ่มและจุดสิ้นสุดเดียวกัน หากไม่มี Snapshot สองเวลาหรือ Label 7 วันที่เก็บตามนิยามจริง การเรียกว่า Growth หรือ 7-day prediction จะผิดความหมายของข้อมูล

### ถ้าพูด Keyword ซ้ำหลายครั้ง Probability จะสูงขึ้นไหม

ไม่ Feature หัวข้อเป็น Binary presence มีหรือไม่มี การพูดซ้ำไม่เพิ่มค่า และระบบแนะนำวิธีเพิ่มสาระ เช่น วิธีทดสอบหรือสิ่งที่ควรอธิบาย ไม่ได้สั่งยัดคำซ้ำ

### ทำไมตอนนี้ไม่แสดงเปอร์เซ็นต์

เพราะข้อมูลจริงยังผ่านโครงสร้าง 0 แถว สิทธิ์ใช้ข้อมูลยังไม่ยืนยัน ไม่มี Fresh Independent Test และไม่มี Qualified Outcome model ระบบจึง Fail-closed ตามเกณฑ์เดิม การไม่แสดงตัวเลขคือพฤติกรรมที่ถูกต้อง

### Classification model กับ Outcome model เหมือนกันไหม

ไม่เหมือน Classification เลือกหมวดเนื้อหา ส่วน Outcome ประเมินกลุ่มผลตอบรับภายในหมวด ทั้งสองมี Registry, Gate และ Artifact แยกกัน Outcome ห้ามทายหมวดแทน Classification

### ทำไมไม่ใช้ AI สร้างเหตุผลเอง

ข้อความคำแนะนำใช้ Template ที่ตรวจสอบได้และผูกกับหลักฐานจริง เพื่อไม่แต่งสเปก คลิปอ้างอิง หรือความสัมพันธ์ที่ไม่มีในฐานข้อมูล Outcome assessment เป็นข้อมูลเสริมและถูกงดเมื่อ Gate ไม่ผ่าน
