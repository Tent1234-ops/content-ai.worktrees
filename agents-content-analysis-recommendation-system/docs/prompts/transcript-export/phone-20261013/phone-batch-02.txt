- ไม่มีคำบรรยายให้รายงานแยก ไม่สร้างไฟล์ข้อความแจ้งข้อผิดพลาด

- หนึ่งคลิปต่อหนึ่งไฟล์ transcript_<ID>.md โดย ID ต้องตรงทั้งชื่อไฟล์ URL และแหล่งข้อความ
- หากแนบไฟล์ไม่ได้ ให้แสดง Markdown แยกบล็อกพร้อมชื่อไฟล์นอกบล็อก ห้ามอ้างว่ามีไฟล์แนบถ้าไม่มี
