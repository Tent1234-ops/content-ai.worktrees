ข้อกำหนด:
- ทำทีละคลิป ข้อความหนึ่งไฟล์มาจากแหล่งเดียว ไม่ใช้สรุป Source Guide หรือคำตอบก่อนหน้าแทน
- ส่งคำบรรยายตามลำดับ ห้ามสรุป ย่อ แปล เรียบเรียง เติมช่วงที่หาย หรือแก้ชื่อรุ่น/ตัวเลข/สเปกจากการเดา
- คงคำพูดซ้ำและช่วงเปิด/ปิด จัดย่อหน้าได้แต่ห้ามตัดกลางคำหรือแบ่งทุก 1,000 ตัวอักษร เก็บเวลาที่มีจริง ห้ามสร้าง Timestamp
- ไม่มีคำบรรยายให้รายงานแยก ไม่สร้างไฟล์ข้อความแจ้งข้อผิดพลาด
- ส่งไม่จบให้หยุด ไม่ย่อส่วนที่เหลือ ใช้ชื่อ transcript_<ID>_partial.md และรายงาน ID กับข้อความท้ายสุดนอกไฟล์ว่า “ยังไม่พร้อมนำเข้า”
- หนึ่งคลิปต่อหนึ่งไฟล์ transcript_<ID>.md โดย ID ต้องตรงทั้งชื่อไฟล์ URL และแหล่งข้อความ
- หากแนบไฟล์ไม่ได้ ให้แสดง Markdown แยกบล็อกพร้อมชื่อไฟล์นอกบล็อก ห้ามอ้างว่ามีไฟล์แนบถ้าไม่มี
